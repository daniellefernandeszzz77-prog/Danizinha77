# Área de Pacotes 18+

Template estático e responsivo com:

- confirmação de maioridade;
- três pacotes configuráveis;
- seleção do pacote e instrução de pagamento por PIX;
- envio de comprovante em JPG, PNG ou PDF;
- redirecionamento ao Instagram após o envio.

## Configuração

Edite somente `config.js` para inserir nome da marca, chave PIX, Instagram, dados dos três pacotes e caminhos das imagens. As fotos podem ser adicionadas em uma pasta `assets/`.

O site ainda contém dados provisórios porque as fotos, os preços, a chave PIX e o endereço do Instagram serão fornecidos depois.

Não coloque senhas, tokens ou credenciais privadas neste repositório.
